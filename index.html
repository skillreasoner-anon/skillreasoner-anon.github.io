How To Play

  • Mouse: hold and drag inside the scene to guide the orange pusher.
  • Touch: drag on the touchpad. Lift your finger and start another drag to keep moving.
  • Keyboard: focus the scene, then hold the arrow keys. Space pauses.

The pusher contacts the block but can pass through walls; the block cannot. Approach different edges to rotate it. Reset returns to the same starting pose.

About This Demo

A hands-on browser adaptation of the paper’s Narrow Passage, Multi-Room, and Winding Maze layouts. It uses the paper’s V6.0 kinematic pusher controller, contact settings, and wall corrections (800 Hz physics, 10 Hz control). These interactive runs are not the benchmark evaluation protocol or the learned policy.

Physics runs on your device. Slower devices may run below real time. The first load downloads roughly 27 MB; no installation is needed.

No analytics, login, cookies, or interaction uploads. The application makes only same-site requests for its files. Static hosting is provided by GitHub Pages.
